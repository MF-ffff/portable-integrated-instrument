# 基于 STM32 与 FreeRTOS 的便携式综合仪器 (Portable Integrated Instrument)

## 📖 项目简介
本项目是一款基于 STM32 的便携式综合测试仪器，集成了万用表、简易示波器与信号发生器的功能。采用 FreeRTOS 实时操作系统进行任务调度，配合 LCD 屏幕实现友好的图形化用户界面（GUI）。项目涵盖了按键交互、UI 绘制、ADC 波形采集、DAC 波形输出等核心功能。

## 🛠️ 功能模块划分
整个系统划分为以下 7 个核心模块：

### 1. 按键驱动与交互模块
**实现内容**：
对开发板上的 4 个“选中”按键和 2 个“控制参数”按键进行扫描与状态检测，并在按键按下时触发回调函数。
**实现思路**：
- 封装按键初始化与扫描逻辑，采用回调函数机制处理按键事件（解耦硬件层与业务层）。
- 例如：当按键 1 按下时，回调函数会执行选中 LCD 屏的“运行模式”面板，并调用蜂鸣器触发音效作为按下的反馈。

### 2. 按键音效反馈模块（含 Bug 修复）
**实现内容**：
在按键按下时，蜂鸣器鸣叫作为交互反馈。
**难点与突破**：
- **修复音效丢失 Bug**：在 FreeRTOS 环境下，蜂鸣器鸣叫期间（任务处于阻塞态），若多次按下按键，会导致后续按键音效丢失。通过优化任务调度机制或引入消息队列/事件标志组，确保所有按键事件都能被及时响应，彻底解决音效丢失问题。

### 3. LCD 屏幕显示与底层驱动模块
**实现内容**：
点亮 LCD 背光，实现基础的屏幕显示与底层硬件驱动。
**实现思路**：
- 配置硬件 SPI 接口，编写底层通信函数，实现单片机向 LCD 屏发送“命令”和“数据”。
- 调用 `lcd.h` 驱动库，完成 LCD 屏的复位操作与基础绘制测试，确保屏幕工作正常。

### 4. 万用表模块（电压与电阻测量）
**实现内容**：
实现基础万用表的测量功能，并将结果显示在 LCD 屏上。
**实现思路**：
- 利用开发板自带的稳压电源模块供电，并将供电电压实时显示在 LCD 屏上。
- 通过 ADC 采样，结合分压电路与运算公式，实现待测器件电压和电阻的测量与换算。

### 5. LCD 界面绘制与 UI 交互模块
**实现内容**：
在 LCD 屏上构建完整的用户图形界面（GUI），并实现界面状态的切换。
**实现思路**：
- 在屏幕上成功绘制出 5 个功能面板（如万用表面板、示波器面板等）和 2 个标签。
- 结合按键驱动，实现通过按钮控制面板的“选中”状态切换；再次按下按钮时，切换对应面板内部的参数选项。

### 6. 简易示波器模块
**实现内容**：
实现波形信号的采集与实时显示。
**实现思路**：
- 将待测信号接入 ADC 模块，配置定时器触发采样（或 DMA 传输），将模拟信号转化为数字波形数据。
- 对采集到的数据进行处理，利用 LCD 库的绘制函数（如画点、画线），将波形实时绘制到 LCD 的“波形面板”上。

### 7. 信号发生器模块
**实现内容**：
实现正弦波、方波等标准信号的输出。
**实现思路**：
- 通过软件算法手动生成各类波形的数据点。
- 将波形数据发送至 DAC（数模转换）模块，经内部转换后，通过外部输出电路将数字信号还原为实际的模拟波形。
